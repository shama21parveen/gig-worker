# Gig Worker Safety + Earnings OS

Gig Worker Safety + Earnings OS is a full-stack web application built for gig workers to manage earnings, shifts, safety, documents, support requests, and profile information from one place.

The project is designed for Indian gig workers and includes a React frontend with a Node.js/Express backend.

## Features

- OTP based sign in and sign up
- Worker dashboard
- Earnings tracking
- Daily, weekly, and monthly earnings views
- Expense tracking
- Upcoming payout overview
- Shift planner
- Safety center
- Documents vault
- Support and grievance submission
- Worker profile management
- Emergency contact management
- English and Hindi language support
- Mobile responsive UI
